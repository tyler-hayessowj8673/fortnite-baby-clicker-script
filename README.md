## What This Script Does

Fortnite Baby Clicker Script is a client-side browser utility for the Fortnite Baby Clicker web game. Its purpose is to take care of recurring click actions, reducing the amount of manual input needed while keeping the process within the browser.

The project targets current web browsers and uses a compact HTML-oriented structure. It is intended for local use and provides a small collection of controls for selecting the click timing and deciding when automation should run.
